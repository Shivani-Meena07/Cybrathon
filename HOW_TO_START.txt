✅ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════════════

Problem: Backend won't start
Solution:
  □ Check Node.js is installed: node --version
  □ Check .env file exists and has PORT=5000
  □ Try: npm install (in backend folder)
  □ Try: npm start again

Problem: Frontend won't start
Solution:
  □ Check Node.js version: node --version (need v14+)
  □ Try: npm install (in frontend folder)
  □ Try: npm run dev again
  □ Check port 5173 is free

Problem: Socket.io connection fails
Solution:
  □ Make sure backend IS RUNNING on port 5000
  □ Check browser console for errors (F12)
  □ Refresh the page (Ctrl+F5 or Cmd+Shift+R)
  □ Hard refresh cache

Problem: Can't access http://localhost:5173
Solution:
  □ Make sure frontend IS RUNNING (see "Local: http://...")
  □ Check terminal for errors
  □ Try different port (check terminal output)
  □ Restart frontend (Ctrl+C then npm run dev)

Problem: Styles look broken
Solution:
  □ Clear browser cache (Ctrl+Shift+Delete)
  □ Hard refresh (Ctrl+F5 or Cmd+Shift+R)
  □ Close and reopen browser
  □ Check CSS files exist in src/
